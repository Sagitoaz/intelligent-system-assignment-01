Chương 7 · Hệ bốn agent: truy hồi → đồ thị → viết → kiểm tra

Mỗi agent chạy đúng một lượt; State và Message được hiện sau từng bước. Khớp với mục 7.2–7.5 của tiểu luận.

Câu hỏi mẫu:
Lần chạy đầu cần nạp mô hình sinh văn bản trên CPU nên có thể mất 30–60 giây.
Hai câu hỏi sai đầu vào (câu rỗng, miền lạ) bị chặn trước khi agent chạy: đó là chốt kiểm soát đầu vào ở mục 7.5.3.
Bấm “Chạy bốn agent” để xem từng lượt.
